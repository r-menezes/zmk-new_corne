# Custom ZMK Config for Eyelash Corne

This repository contains a customized ZMK firmware configuration for the **Eyelash Corne** keyboard. 

> **Important**: This keyboard is not the same as [foostan's standard Corne](https://github.com/foostan/crkbd) and will not work with standard `corne` firmware.

## Key Modifications & Features

This configuration adopts an advanced layout philosophy customized from [urob's zmk-config](https://github.com/urob/zmk-config). It utilizes various ZMK modules and helper macros to enable powerful features:

- **"Timeless" Home Row Mods (HRMs)**: A carefully tuned, balanced hold-tap configuration that allows for fast typing on the home row with virtually no misfires or typing delays.
- **Smart Layers (Numword & Mouse)**: Features a sticky "Numword" behavior that activates a number layer temporarily while typing digits and automatically deactivates on other keypresses.
- **Enhanced Combos**: Designed to use combos for quick symbol access without always relying on dedicated layer hold-switching.
- **Magic Shift & Caps-word**: Intuitive sticky-shift implementations that capitalize single letters or trigger Caps-word on double-tap without breaking typing flow.
- **Hold-Tap Navigation**: The navigation cluster serves dual purposes (e.g., tap for arrows, long-press for document-wide operations like Home/End).
- **Automated Keymap Drawing**: Fully integrated with `keymap-drawer` (and `zmk-helpers` includes) so that maintaining the `.keymap` file automatically generates a beautiful SVG visualization of the layouts.
- **Soft-off / Deep Sleep**: Supports ZMK soft-off macros to put the device into a deep sleep state for travel.
